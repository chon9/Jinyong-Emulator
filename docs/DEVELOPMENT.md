# 網金游俠模擬器

Godot 4.6.3 的武俠模擬遊戲，以文字呈現門派、學藝、消點、自修與戰鬥，可單機，也可透過 Steam Spacewar 480 或區網聯機。v0.2 的經典介面沿用使用者 JY-Mini OL 專案的字型、四張地景、玉石與編繩框、羊皮紙卷軸、燈籠及底部 HUD；玩法與戰鬥仍以文字操作。

目前可玩內容：**208 個相連地點、221 位具有獨立對話的 NPC、114 件物品、110 種有實際遭遇地點的敵人、11 個門派、115 門武學、12 條人物故事支線**。各項數量由引擎測試計算，見 `test-results/world.json`。這是一個可玩的模擬版本；戰鬥數值、成長公式、地圖捷徑與學習條件有本作調整，尚不能宣稱與特定版本的「網金游俠」完全一致。

## 啟動

**Windows 獨立版**：解壓縮 `build/Youxia-0.3.0-Windows-x64.zip`，雙擊 `Youxia.exe`。不需要安裝 Godot 或 Python；請保留同資料夾的 DLL 與 `steam_appid.txt`。程式已內嵌遊戲資料，沒有另外的 PCK 檔案。獨立版使用 Windows 標準的 `%APPDATA%/Godot/app_userdata/網金游俠模擬器/` 存檔位置，可讀取 v0.1 的角色進度。

重新製作 Windows x64 Release：執行 `.\tools\export_windows.ps1`，需要 Godot 4.6.3 與已安裝的相同版本 Windows export template。輸出為 `build/windows-0.3.0/Youxia.exe` 及完整 ZIP；不覆蓋舊版發行資料夾。圖示來源為 `assets/icon.ico`，可用 `.\tools\make_icon.ps1` 重建。

**從原始碼啟動**：

在 PowerShell 執行：

```powershell
.\tools\run.ps1
```

預設沿用本機 `K:\Godot\Godot_v4.6.3-stable_win64_console.exe`。若引擎在其他位置：

```powershell
.\tools\run.ps1 -Godot 'D:\Godot\Godot_v4.6.3-stable_win64_console.exe'
```

也可直接用 Godot 4.6.3 匯入根目錄的 `project.godot`，按 F5 執行。第一次開啟先匯入：

```powershell
.\tools\run.ps1 -Headless -NoSteam -Import
```

啟動工具會把 APPDATA 與 LOCALAPPDATA 指向專案 `.tools/`，因此存檔在 `.tools/appdata/Godot/app_userdata/網金游俠模擬器/youxia_save.json`。直接用 Godot 編輯器啟動則使用該引擎正常的 `user://` 位置；這兩種啟動方式各有自己的存檔。每 30 息自動儲存，遊戲內 F5 手動存檔，離開也會儲存；保留一份 `.bak`，主檔損壞時會讀取備份。

## 前十分鐘

1. 在江湖頁選門派山門，按「拜入」。十一門派為少林、武當、峨嵋、華山、恆山、全真、古墓、靈鷲宮、星宿、血刀門、丐幫。本作不套用原版的性別限制。
2. 打開武學頁。師父在身邊時，「當地師父」會列出可教武學、前置等級、費用與上限；按「消點」學習。要找其他師父，可按「尋師訪道」的尋路按鈕，再逐步沿路移動。
3. **消點**每次花 `5 + 目前等級 × 2` 學點、授課銀兩與 3 精力，直接升一級，每息最多一次。必須同地點、符合門派與前置武學，且未達師父上限。控制台「自動消點」會重複向上次選定的師父學習，資源不足或無法授課時停止。
4. **自修**只修已學武功。每息扣 2 精力與 1 內力，依武學難度累積熟練；熟練門檻為 `12 + 目前等級 × 3`。不花學點與銀兩，可超過師父授課上限，最高 100 級。控制台可切換修練武學。
5. 返回揚州城，接取「城郊除患」，前往城郊荒野按「自動刷怪」。戰鬥每秒一輪，勝利獲閱歷、學點、銀兩與掉落。擊敗三隻野犬後回城領賞。學點可繼續用來消點。
6. 需要休息時先結束戰鬥，按「盤膝打坐」。氣血低於 45% 時，自動補血會消耗行囊裡的金創藥；沒有藥且氣血不足四分之一時不再開新戰鬥。重擊花內力提高傷害，防守降低攻擊與受傷。
7. 在圖鑑搜尋人物、地點、敵人、武學與物品。在故事頁選要拜訪的人，交談依序推進人物支線；完成後可作出一次抉擇並領獎。已讀內容和選擇保存在角色中。

揚州城集中販售一般物品，其他商人使用各自貨單。武器與防具影響實際攻防，食品藥物能恢復精氣，材料可出售，任務信物可收藏。戰敗扣 8% 身上銀兩，回揚州城恢復一半氣血；此為本作休閒規則。

55 件任務物品另有本作的搜查與交付委託：當地人物會顯示所需物品及線索，沿路前往目標地點，按「仔細搜查」取得遺物，再回委託人身邊交付，獲得銀兩、學點及貢獻。每個地點只能搜查一次，每件委託只能領獎一次。所有 114 件物品都有實際取得途徑；這些委託是本作針對既有資料改編的簡化收集玩法，不等同原版任務鏈。

指令框也可輸入：`前往 地名`、`拜師 武當`、`消點 武功名`、`自修 武功名`、`裝備 物品或武功`、`打怪`、`逃跑`、`掛機 刷怪`、`停止`、`打坐`、`購買 金創藥`、`使用 金創藥`、`任務`、`領賞`、`改名 名字`、`說 你好`。輸入「幫助」可查看提示。NPC 對話與故事抉擇使用頁面按鈕。

## Steam 與區網

已沿用你提供的 `JY-Mini OL` 專案中的 GodotSteam GDExtension 4.23，插件及授權一併放在 `addons/godotsteam/`，不依賴原專案繼續存在。使用 App ID **480**，大廳標記為 `youxia_text_v2`，不接受其他 Spacewar 遊戲的大廳。所有玩家需使用相同的 v0.2 版本；舊版連線不相容，但角色存檔可沿用。

- Steam：雙方使用不同 Steam 帳號，先開 Steam 和本遊戲。房主在「聯機」頁按「Steam 開房」，複製大廳編號給朋友；朋友填編號按「加入大廳」，也可用房主的「邀請好友」打開 Steam 覆蓋介面。480 測試建議兩邊先開遊戲，再接受邀請。
- 區網：房主按「區網開房」，朋友填房主 IP 並連線，使用 UDP **24780**。同機兩個程序使用 `127.0.0.1`。一般網際網路直連仍需自行處理路由器轉送，Steam 使用 Steam 的傳輸層。
- 房主結算戰鬥、獎勵、消點、自修與故事。訪客角色存在房主的世界；Steam 由傳輸層提供 SteamID 識別。區網使用安裝代碼，適用互相信任的朋友，不是公開伺服器的帳號驗證系統。
- 主機離線、連線失敗或逾時會回到自己的單機角色。重回同一房主可恢復該房主保存的角色；不恢復未完成戰鬥或自動掛機。沒有主機移轉。

Steam 單機煙霧測試已成功完成插件載入、初始化、建立大廳及建立主機傳輸層；**兩個 Steam 帳號的跨機連線仍需實機驗收**。區網雙程序的聊天、戰鬥、同步、斷線與重連已自動驗證。正式發行時應替換成自己的 App ID 與發行設定。參考 [Valve 的 Spacewar 範例說明](https://partner.steamgames.com/doc/sdk/api/example)。

## 多人互動（v0.2）

按 **F7** 或右側「人際」燈籠，選擇玩家進行互動。右上角顯示在線玩家、氣血、隊長標記與待回覆邀請。右側「系統」燈籠或 F8 開啟原本的聯機頁。Ctrl+1–7 對應七個燈籠，Esc 返回江湖；底部訊息列會顯示操作結果與失敗原因。

- **組隊**：同地點邀請，對方接受後入隊，最多五人；隊長可邀請、踢人、移交隊長。隊長離線時自動推選接任者；剩一人時解散。邀請 45 息逾時。
- **跟隨**：隊員自行開啟跟隨後，與隊長同地點且未交戰時，隨隊長沿出口移動；不傳送遠處或交戰中的隊員。
- **共同刷怪**：隊員在同地點、閒置且氣血至少 25% 時，尋敵會建立同一場戰鬥；怪物每多一人增加 50% 氣血。全員攻擊同一目標，敵人隨機反擊一名隊員。存活者按開戰人數平分閱歷、學點、銀兩並取得擊殺／懸賞計數；掉落只擲一次，指定一名存活隊友領取。逃跑或倒地者不領本場獎勵。
- **援護**：消耗自己一瓶金創藥，為同地點隊友恢復最多 70 氣血；不能介入玩家對戰。
- **切磋**：同地點發出邀請，接受才開戰；雙方輪流先手，可使用策略、藥品與認輸。結束恢復開戰前氣血與內力；藥品仍按實際使用消耗。無金錢、裝備損失或可刷取獎勵。
- **野外 PK**：雙方先開啟 PK，且在非安全區，才可直接開戰；禁止攻擊同隊玩家，交戰中不能關閉 PK。敗者送回揚州、恢復半血並關閉 PK。PvP 勝負另行記錄，不套用刷怪掉落。
- **交易／贈送**：選擇物品、數量及售價，對方接受時再次檢查雙方位置、戰鬥狀態、庫存及銀兩，再原子交換；售價 0 是贈送。不能交易任務信物或身上最後一件已裝備的武器／防具。邀請失效或資產改變時不扣款。
- **聊天**：底部切換世界、隊伍或密語；密語對象在「人際」頁選取。隊伍與密語只送指定收件者，不向其他玩家廣播。

隊伍、邀請、跟隨、PK 開關及未完戰鬥是本次連線狀態，不隨存檔或重連自動恢復；PvP 戰績與角色進度保存。以上均為本模擬器規則，不宣稱完全等同原作 PK／隊伍制度。

測試包含內容數量、地圖完整連通、對話與故事資料、敵人實際出現、十一門派拜師、師父條件與上限、消點節流、自修成本與升級、刷怪與懸賞、物品效果、防重領、介面七頁、文字聊天安全顯示、存檔覆寫與讀回，以及兩個真實 Godot 程序的連線與重連。多人專項另驗證邀請授權、五人上限、戰鬥與交易狀態、獎勵守恆、資產改變、斷線清理與收件者隱私。結果寫入 `test-results/`，該資料夾不進版本控制。

## 內容與程式結構

- `scripts/world.gd`：不依賴 UI 的權威規則引擎。
- `scripts/session.gd`：單機、ENet、Steam 的連線生命週期、意圖與快照、角色保存。
- `scripts/social.gd`：隊伍、邀請、多人共戰、切磋／PK、交易、援護與定向聊天。
- `scripts/steam_bridge.gd`：GodotSteam 4.23 大廳、邀請、回呼與逾時。
- `scripts/main.gd`：純文字介面、聊天、指令、尋路與圖鑑。
- `scripts/classic/`：從使用者 JY-Mini OL 專案改編的框、主題、燈籠，以及新的經典版面。
- `data/catalog.json`：從使用者提供的專案轉換的獨立資料，另含新增遭遇；新專案調整了數值、部分授業方式及封閉地點連通。
- `data/stories.json`：12 條自行撰寫的跨作品人物訪談與抉擇，依金庸人物脈絡改編，並非原著逐字內容。
- `tools/build_catalog.py`：可重現的內容轉換工具，來源只讀；執行遊戲不需要 Python 或原專案。

其他原版規則，例如實戰／學點精確公式、師承考驗、門規、叛師、原作技能招式效果與全套任務鏈，尚未逐項校準。此版本提供可玩循環與內容規模，後續應按指定的原版版本逐項比對。
