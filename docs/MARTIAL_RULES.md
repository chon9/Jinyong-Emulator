# 武學與兵器規則（v0.3.1）

這次修正以金庸 Online 的技能名稱、基本功分類及兵器相容性為準，不以小說中的武功名稱推測遊戲分類。原專案與官方分類矛盾時，使用有紀錄的官方分類覆寫。

## 分類與運用

基本功保留原資料的十七個名稱：基本刀法、基本劍法、基本鞭法、基本棍法、基本槍法、基本內功、基本刺術、拆招卸力、搏擊格鬥、閃躲縱躍、基本身法、基本陣法、基本毒術、基本醫術、基本暗器、讀書識字、交易之道。

官方介紹區分搏擊格鬥（拳掌入門）、基本刺術（指法）、拆招卸力、閃躲縱躍及基本身法：[武學屬性](https://jy.orientaldragon.com.tw/node/21)。本作不再把這些基本功全部匯入成沒有功能區別的 BASIC。

| 本作類型 | 相容兵器／作用 |
| --- | --- |
| 搏擊拳掌 FIST | 徒手、爪類搏擊兵器 |
| 刺術指法 STAB | 徒手、爪類搏擊兵器；與槍法分開 |
| 刀 BLADE、劍 SWORD | 分別需要刀、劍 |
| 棍杖 STAFF、槍 SPEAR、鞭 WHIP | 分別需要棍杖、槍、鞭 |
| 內功 INNER | 獨立運用欄，增加本作攻防加成 |
| 輕功 LIGHTNESS、閃躲 DODGE | 獨立輕功欄，增加本作防禦加成 |
| 拆招 PARRY | 基本拆招等級被動影響防禦 |
| 陣法、暗器、毒術、醫術、門派修養、生活技能 | 可學習修練，不得當作普通外功攻擊 |

官方武學表明列倚天屠龍筆法為「槍」；因此覆寫來源專案的 STAB／基本刺術，改為 SPEAR／基本槍法。太極拳保持拳法，不因武當派而變成劍法：[官方武功分類表](https://jy.chinesegamer.net/new_data/flower/index-6.htm)。

官方絕學說明要求手持符合的兵器：[絕學系統](https://jyex.chinesegamer.net/jy3_4.asp)。本作將相容檢查一致用於普通外功、單人刷怪、共同刷怪、切磋與 PK。更換兵器時自動選擇已學且相容的最高等級外功；沒有相容武功時拒絕裝備並提示學藝。卸下兵器時改用已學徒手外功。

官方將內功與輕功列為不同功能，輕功影響移動、脫逃及閃躲：[內功與輕功介紹](https://jy.chinesegamer.net/new_data/light/light-1.htm)。本作只實作文字回合戰鬥中的支援加成，沒有原版戰棋移動格數。

## 消點與自修

- 師父授業仍須同地點、同門派、符合技能前置條件，消耗學點、銀兩與精力。
- 匯入資料保留基本功上限、師父授業上限、技能等級前置及個別自修上限；不再把所有基本功硬截成 100 級。
- 紫霞神功、峨嵋九陽功、九陰真經的本作授業入口只授 1 級，後續靠自修。紫霞與峨嵋九陽的自修上限分別採來源資料的 65 與 80；這些數字屬來源專案採用的版本設定，並非所有官方年代通用。
- 自修每息扣 2 精力、1 內力；熟練門檻 `12 + 等級 × 3`，增量依難度。消點費用 `5 + 等級 × 2`。這些速度與費用是本作平衡公式。

## 明確保留的改編與未完成項目

本次完成分類、兵器限制、運用欄、基本功傷害連動與存檔遷移，並未完成特定年代的全量機制還原。

來源專案部分事件武學，在本作仍透過有技能前置的師父入口取得；沒有完整原版任務旗標、屬性、善惡、性別及實戰門檻。拜師贈入門武功、丐幫分舵師承與消點條件也是本作改編。混天功歸內功、打狗棒法歸棍杖；本作「逍遙遊」保留拳掌套路，不將它和後期的「逍遙遊身法」混為同一門。

原版不同層級武學有不同的學習方式。例如官方究極版的絕學不得消點，九陰真經另有任務轉換限制；目前尚未建立絕學、精要、必殺技的完整分層或九陰任務轉換。陣法協同、暗器投擲與毒術狀態也尚未實作，不能因已在圖鑑或可自修就視為可出招。原版內功特殊效果、屬性公式、命中閃躲機率、招式威力與消耗尚未逐門還原。

練習長槍與練習鐵爪是本作新增的低價練習兵器，補足原匯入商店缺少的類型，不標成原版物品。

## 存檔與聯機

舊存檔「基本拳腳」等級與熟練合併至「搏擊格鬥」。若舊外功欄放的是內功或輕功，移至對應欄，再選合法外功。無相容已學武功的兵器會卸下，仍保留在背包。遷移不移除已學武功或扣除其等級。

聯機協議升至 3，Steam 大廳標記 `youxia_text_v3`，避免舊版客戶端混用不同運用欄位與規則。請全員更新至 v0.3.1；角色存檔可沿用。
