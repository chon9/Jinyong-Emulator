# v0.11.1 — 人物裁切與戰鬥音效修正

對話立繪、城鎮頭像與戰鬥現在共用圖集排除規則。修正無錫城賀若水對話右側混入鄰人的碎片，並檢查全部364個人物動作格，為52個受污染的矩形加入排除區。保留原始圖像及人物本體，不再只對戰鬥套用遮罩。

音效改用獨立 Effects 音軌，預設播放增益提高6 dB。戰鬥右上可分別開關音樂、音效，選項新增「試聽刀劍音效」。音效音量或靜音立即作用於正在播放的聲音；明確按開啟時也能恢復先前存為零的音量。保留玩家原有靜音偏好。

修正瀏覽器掉幀時越過命中時點，或下一個動作先到而漏播命中聲的問題。空閒播放聲道優先使用，避免後續動作過早切斷較長的招式聲。

驗證：原有及新增原生測試合計20,917項通過；瀏覽器重現同地點對話，以像素檢查原碎片位置已透出對話框底色。關閉音樂後測量實際刀劍及戰鬥輸出，並驗證音效靜音、零音量恢復、瀏覽器暫停後恢復及重新載入。四人戰鬥動畫與Windows打包EXE啟動亦通過。

目前仍使用原有圖集的關鍵姿勢動畫，並未把所有人物重繪成逐幀動畫。
