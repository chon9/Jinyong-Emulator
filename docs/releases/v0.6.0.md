# 網金游俠模擬器 v0.6.0 — 生活技能掛機

下載 **Youxia-0.6.0-Windows-x64.zip**，完整解壓後執行 **Youxia.exe**。聯機玩家請一起更新至協議 **7**。

- 新增上方 **生活** 入口與 **Ctrl+0**，從尋師、付費領工具，到工作地點尋路、選配方與開工都能直接操作。
- 接入 JY-Mini OL 的 **11 種生活技能、38 張配方、62 個工作地點**：種田、樵夫、釣魚、廚師、挖礦、打鐵、鑄劍、工匠、織布、裁縫、獵人。
- 支援指定 1／10／30／100 次或持續工作；精力不足可自動打坐，回滿後續作，或選擇自停。缺工具、材料或條件不足仍會停止。
- 工作頁顯示成功率、熟練、耗精、材料與計時；缺料可跳到採集、製作或商店，成品與收成可直接開出售頁。
- 礦石 → 鐵塊 → 武器工具，麻 → 線軸 → 布匹 → 衣服，獸皮 → 皮革 → 皮甲。狩獵實際使用武功進行單人戰鬥，勝利後才獲皮肉。
- 多人由主機驗證計時與成本；停止或中斷不發未完成產物，存檔保留熟練與物品，不補算離線收益。

驗證包括全部配方實際製作、失敗保料、調息續作、取消與工具中途移除、狩獵、存檔、滑鼠完整操作，以及雙程序聯機同步。Windows EXE 已重新匯出，README 增加實機生活頁截圖；發布前檢查來源與 ZIP 的敏感資料。

配方與數值保留參考專案的來源標記，部分屬其設計提案或後期資料；並非原版官方經濟的逐值復刻。兩個 Steam 帳號跨機驗證仍未完成。
