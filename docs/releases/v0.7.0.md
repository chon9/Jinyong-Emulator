# v0.7.0 · 青溪失鏢

預設遊戲重整為 Godot 視覺化武俠首章，Windows 與網頁共用實作。

- 八處地點的點擊地圖、明確的下一步導航、NPC 對話與分支選擇、七步主線與完整結局。
- 三位可招募同伴組成四人隊伍，各有身世、外功與天賦；前後排、三路陣型可換位。
- 依速度出手的隊伍戰鬥：聚氣、真元、調息、前排阻擋、越陣、流血追擊、破甲、毒、清毒、護陣與打斷蓄力。
- 華山／武當／少林入門方向，外功／內功／輕功搭配、帶條件的華山進階學藝、消點與定時自修。
- 可買可賣的市集、採藥支線、戰鬥用藥與首領重戰。
- 新舊進度分別保存在同一存檔，瀏覽器可匯出／匯入；音樂與最新 Windows 下載入口保留。
- 舊版江湖、Steam／LAN／WebSocket、生活技能與舊副本保留在設定入口，舊版左上可返回新章。

本版是新方向的完整第一章，新章目前為單機；大世界與舊版內容尚未全部轉換成隊伍玩法。故事與數值為本專案自訂，參考《煙雨江湖》的角色、武學、戰鬥與探索方向，沒有宣稱逐值重製官方公式。參考畫面未作為遊戲素材打包，角色與場景沿用用戶提供的 JY-Mini OL 資源。

解壓 Windows ZIP 的完整資料夾後執行 `Youxia.exe`。網頁版：[jy.chon9.com](https://jy.chon9.com)。玩法與研究：[青溪新章](../JOURNEY.md)。
