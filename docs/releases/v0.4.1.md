# 網金游俠模擬器 v0.4.1 — 任務與買賣入口

解壓縮 **Youxia-0.4.1-Windows-x64.zip**，執行 **Youxia.exe**。請保留同資料夾的 DLL、steam_appid.txt 與授權文件。

這次先處理基本操作：任務、商店、行囊各有常駐導覽入口，點「前往」會直接開始趕路。

- **任務**：可接、進行中、全部、已完成分頁；支援搜尋、條件說明、目的地、下一步、對話選項、交付與領獎。加入門派後不再隱藏一般任務。NPC 旁能直接接取或繼續任務。
- **商店**：獨立購買／出售介面，物品搜尋、數量、單價與總價。主機一次完成扣款與物品交換；銀兩不足、任務物品與裝備保護均有明確原因。
- **找商人**：無商店的地點會列出附近商店與步數，點選後自動前往。也可搜尋販售某物品的商店。
- **行囊**：保留使用與裝備，加入買賣捷徑；可先卸下兵器或防具再出售。
- **流程修正**：剿滅山賊不再把怪物當成 NPC，並按任務要求安排三名敵人；補回華山內奸、血海魔功等任務的階段物品事件。

測試包括滑鼠點擊走完接任務、趕路、交信、領獎、購買與出售，以及兩個本機程序之間的批量買賣同步。保留舊存檔；聯機玩家需一同更新至 **v0.4.1／協議 5**。

範圍：仍只有 29 筆匯入的來源任務定義，部分後續尚未開放；本版沒有聲稱補齊參考專案的 86 個任務。跨機 Steam 雙帳號驗證仍未完成。
