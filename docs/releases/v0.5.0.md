# 網金游俠模擬器 v0.5.0 — 任務與副本

下載 **Youxia-0.5.0-Windows-x64.zip**，完整解壓後執行 **Youxia.exe**。聯機玩家請一同更新，協議為 **6**。

- **新增 20 條來源任務**：金盆洗手上下篇、雲兒小姐的煩惱、尋找楊康、程清霜送藥、痴情梁發、清為尋木、全真送信、王處一取藥、雁門關拓印等。共有 49 筆匯入任務定義，另加四份副本討伐委託。
- **接回任務流程**：場景動作、砍木與採集、時辰限制、連續考較、累計擊殺、階段物品與丐幫袋位獎勵。黑玉斷續膏、龍門遺案及丐幫一／二袋不再因缺少場景入口而中斷。
- **可重複委託**：完成次數與冷卻存檔，冷卻期間不能重領；任務頁顯示何時可再接。等待型任務保存世界時鐘，重開後繼續剩餘等待。
- **四個文字副本**：黑風寨剿匪、銅人試陣、血刀密窟、高昌秘窟。每個三關，支援單人與最多五人隊伍；銅人試陣三陣合計十八名銅人。
- **組隊副本流程**：入口集合、隊長建立、各自準備、逐關戰鬥、關間療傷與援護。獨立副本互不影響；隊長離線可交接，全員失去戰力則失敗。
- **通關與首通**：每位在場隊員各領一次通關獎；首通另給學點及道具。通關自動入帳，退出或戰敗沒有部分獎勵；首通與冷卻保留，未完成副本不跨存檔恢復。

驗證包含 26 條完整任務驗收路徑、可重複任務再次完成、四個副本的真實戰鬥、五人隊伍、戰敗／退出／斷線、首通防重領、滑鼠操作與副本存檔。兩個本機程序另外驗證組隊副本狀態和獎勵同步。

副本及部分對話／數值是本作改編，並非官方副本重製；銅人試陣不代替原版出師考核。尚未補齊參考專案全部 86 個任務，也未完成跨機 Steam 雙帳號驗證。
