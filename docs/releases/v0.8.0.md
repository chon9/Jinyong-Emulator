# v0.8.0 · 山河行旅

從青溪石街出發，結識不同高手，練武、配隊，再去挑戰更遠的江湖。

- 重建青溪街景：街道尋路、人物交談、跟隨鏡頭、小地圖、八處地點目錄。
- 世界地圖十六處據點、十五項遠行遭遇／切磋，顯示建議修為、探索與首勝進度。
- 十位角色含主角，四人出戰；六位新同伴由遠行首勝招募。候補保留修為，主角可研習其武學傳承。
- 修行上限三十重；武林論劍為後期挑戰，首勝獲得武林盟主稱號。
- 六種每日活動：送信、守爐、運鏢護貨、指點、採藥、舊倉試煉，附次數、獎勵和逐步導航。UTC+8 零時刷新。
- 使用玩家提供的金庸群俠傳5角色圖集、城鎮、世界地圖、命中特效及音效。移除線段武器，音效有獨立開關及音量。
- 網頁分塊校驗快取、三路下載、斷線重試、損壞分塊修復、場景準備進度；進入遊戲前準備戰鬥資源。
- 舊存檔可遷移；新章、舊版江湖與 Windows 備份共存。網頁工具列保留 Windows 最新版下載。

目前完整可行走的城市為青溪，其餘據點是對話與戰鬥場景；遠行故事仍屬簡短遭遇。新章為單機四人隊伍，自訂數值與原創人物；舊版聯機功能仍在設定中的舊版江湖。

完整玩法、驗證與來源範圍見 [JOURNEY.md](../JOURNEY.md)。
