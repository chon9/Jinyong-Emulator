# 網金游俠模擬器 v0.3.0

A Windows x64 build of the text-driven wuxia simulator, with classic UI styling, multiplayer interactions, and the JY-Mini OL soundtrack.

## Play

Download **Youxia-0.3.0-Windows-x64.zip**, extract the entire archive, and run **Youxia.exe**. No Godot installation is required. Keep the bundled DLLs and `steam_appid.txt` beside the EXE.

## In this release

- Five BGM tracks with town, wilderness, dungeon, battle and boss selection, crossfades, saved volume/mute preferences, and a track picker in **系統 / F8**.
- Classic parchment scrolls, jade frames, lantern menus, landscape art, calligraphic font, and bottom status bars and hotkeys.
- Five-player parties, invitations, leader transfer, following, shared PvE, divided rewards, ally healing, party chat, and private messages.
- Consensual duels, opt-in wilderness PK, face-to-face trading, and gifts.
- 208 connected locations, 221 NPCs, 114 items, 110 enemy types, 11 sects, 115 martial arts, 12 character storylines, and 55 artifact commissions.
- Teacher prerequisites and instruction caps, 消點, self-study, hunting automation, inventory-based healing, bounties, and save recovery.

## Useful keys

**F1** self-study · **F2** meditate · **F3** seek enemies · **F4** medicine · **F5** save · **F6** world · **F7** player interactions · **F8** music and multiplayer settings.

## Multiplayer and saves

Everyone should use v0.3.0. Steam development networking uses Spacewar 480; start Steam and the game on both computers before joining. LAN uses UDP 24780. The host saves guest progress; host migration is not implemented.

Existing v0.1/v0.2 character saves remain compatible. Saves live under `%APPDATA%\Godot\app_userdata\網金游俠模擬器\`. Development launcher saves remain separate.

## Validation and limits

Automated checks cover world content, learning, rewards, social interactions, music playback/preferences, UI, persistence, and two-process LAN scenarios. The packaged Windows build is also launch-tested. Steam initialization and lobby creation work; two-account cross-machine Steam play remains unverified.

Game rules and numerical balancing are simulator adaptations, with no claim of complete original-version parity. Asset and soundtrack rights remain with their respective owners; bundled notices describe provenance and licenses.
