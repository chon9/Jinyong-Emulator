# v0.12.0 — 人物先於任務

重寫129份自由江湖支線、41位可招募人物和207位居民的對話。黃蓉拆飯錢騙局，令狐沖還酒債，段譽面對不肯照做的殺人命令；人物的脾氣與處境決定怎樣辦事。取消一律找證物、打一場、二選一的流程，音律、棋局和營地支線會依選擇改變途中走法。

- 新增16位故事配角立繪，苗人鳳、任我行、蘇星河、瑛姑、梅莊四友使用自己的角色。具名群俠切磋使用相應人物、兵器和武功。
- 任務進度與招募條件改由旁白說明，NPC保留人物口吻；交情、個人任務與修為門檻仍生效。
- **首次載入或匯入舊版自由江湖會重新開局。先完整備份，驗證成功才重開；備份失敗保留原進度。** 可由「選單 → 匯出重寫前舊檔」取回，Windows會打開備份資料夾。新版存檔其後不再重置。經典版角色與聲音偏好保留。
- 保留人物裁切修正、41位群俠專用姿勢、兵器／招數特效、獨立音效音量、預載驗證與快取修復。

Windows：下載 `Youxia-0.12.0-Windows-x64.zip`，完整解壓後執行 `Youxia.exe`。網頁：[jy.chon9.com](https://jy.chon9.com)。新版故事原稿、研究範圍與備份規則見 [NARRATIVE.md](https://github.com/chon9/Jinyong-Emulator/blob/main/docs/NARRATIVE.md)。
