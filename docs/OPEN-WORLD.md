# 自由江湖與《金庸群俠傳3》Flash 內容對照

v0.10.0 預設為自由探索；任務全部可選，招募與個人支線分開。以 Flash 正式／1.08 與賀歲版公開攻略作內容基線，並非把手遊或其他重製版混入統計。

| 項目 | 目前可玩內容 | 驗證方式 |
| --- | --- | --- |
| 公告事件 | 45 個事件槽位各有一份獨立委託 | `JY3-COVERAGE.json` 的 1–45 對應；包含兩個門派衝突槽位 |
| 招募人物 | 41 位新增人物，包含儀琳；另保留9位原創同伴 | 逐位到所在地邀請，重複邀請不複製角色 |
| 個人支線 | 41 條，可先招募、日後再辦 | 每條都有實際步驟、報酬與好感紀錄 |
| 村莊／門派／場所委託 | 35 條 | 具體目的地、物資交付或戰鬥、回報 |
| 地點 | 16 區域、100 處命名場景 | 每處至少兩位可對話人物；進入不自動開戰 |
| 對手 | 100 種獨立立繪、不同參數與出招行為 | 可從圖鑑尋訪並挑戰；100 個來源格影像雜湊均不同 |

合計 **121 份可選委託**，不把反覆打同一場、每日重置或同一任務的每個步驟再算成新任務。仍不宣稱涵蓋所有 Flash 修改版本的全部隱藏分支；未復刻原腳本的隨機出現機率、原物品收集圖鑑或精確傷害公式。公告題材有明確映射，劇情步驟與對白為本作重新編寫。

- [招募攻略彙整](https://blog.sina.cn/dpool/blog/s/blog_7e7f9ac00100svkm.html)：補核人物名單，特別包含儀琳；其中西夏公主通常不可招募的說法與其他攻略有分歧。
- [Flash 攻略補充](https://ak963520.pixnet.net/blog/posts/2024940377)：比對公告與人物差異。

採聯集處理招募版本差異：本作讓西夏公主可招募，半瓶神仙醋為彩蛋；額外高手也能同行。沒有照搬五日拜師／一年出師期限、先清首章或道德值鎖招募，以符合自由探索方向。

## 怎麼開始

1. 新角色在牛家村村口。點穆念慈頭像，再選「邀請同行」或「委託與故事」。
2. 到牛家客棧可尋訪黃蓉；地圖與人物名冊也提供直接尋訪入口。
3. 委託接下後移到「進行中」。點「前往目標」，需要交談時會打開當事人；交付確實消耗物品，戰鬥步驟必須獲勝，報酬只發一次。
4. 在同伴頁安排四人、六個陣位與候補；武學頁配置外功、內功、輕功。到師父處消點，或原地計時自修。
5. 打不過便撤退、換人、修行；進入地點不會自動戰鬥。地圖上的「武林論劍」隨時可試，首勝取得盟主紀錄。

場景採浮動人物頭像與對話。青溪街巷保留可行走區，建築及渡口改為入口光圈。100處場景共用4張新增背景，並非100座可行走城市。v0.10.1 的207位地方居民／服務人物使用32張新繪頭像，同區域不重複；都有姓名、具體職業、各自的生活對白和地方見聞。不同城市仍會重用頭像。

15組原創角色／兵器配置各有4格新繪戰鬥姿勢（站姿、蓄勢、出招、守勢）。每格獨立計算身高、頭部與腳底；來源裁切線沿透明間隙校準，長武器不再決定人物大小。其他新增群俠與100位對手仍採單張站姿配程式突進／受擊。既有主角保留專用行走影格。

## 存檔與刪除

進度仍保存在同一備份的 `chapter`，新增 `open_world` 保存委託步驟、選擇、交情、見過的人與探索紀錄。舊版進度可匯入；戰鬥、自修和行程不跨讀檔恢復。

選單提供「刪除存檔／重新開始」，預設焦點在保留。取消不變；確認清掉本機角色、候補與任務，連同舊自動備份處理，避免下次載入復活。網路房主保存的其他玩家資料不在本機重置範圍。

## 美術與測試

21張新增素材（10張敵人圖集、5張群俠圖集、1張平民圖集、4張場景、1張補繪穆念慈）以內建 imagegen 產生。提示詞見 [art/open-world-jobs.json](../art/open-world-jobs.json)，來源矩形由 `tools/index_open_art.py` 讀取透明度計算，沒有重畫或程式合成生成圖像像素。

v0.10.1 再新增19張圖集：15張角色動作、4張居民頭像；完整提示詞與檔案清單見 [art/visuals/prompts.json](../art/visuals/prompts.json)、[art/visuals/assets.json](../art/visuals/assets.json)。`tools/calibrate_visuals.py` 只讀取原PNG的透明度，輸出195組人物的來源範圍、身高、腳底及頭像資料，不修改圖像像素。`visual_consistency_test.gd` 檢查同城頭像唯一、裁切來源及戰場邊界；`browser_visual_test.py` 透過實際按鈕逐一拜訪嘉興十處場景，再匯入四人隊伍觀察完整一輪施招。

`tests/open_world_test.gd` 逐一完成121任務、招募41人、實際結算委託戰鬥、建立100對手戰鬥、驗證存讀檔和重複領獎。`journey_ui_test.gd` 驗證可見操作接線；`browser_open_world_test.py` 真正點擊匯出後的 Canvas，檢查對話、完整委託、招募、買賣、挑戰及刪檔後重新整理。載入重試、快取損壞修復與實際音訊另外回歸。
