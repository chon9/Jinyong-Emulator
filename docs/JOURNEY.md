# 青溪失鏢：新的開發方向

v0.7.0 的預設場景為 `scenes/journey.tscn`。Godot 原生與 WebAssembly 共用同一份 GDScript，核心放在角色、武學配置、隊伍分工、可觀察的敵招與有始有終的故事。

第一章有八處互相連通的地點、主角與三名可招募同伴、七步主線、採藥支線、三場故事戰鬥、首領重戰、買賣、三種師門入門方向，以及實際影響戰鬥的消點與自修。這是新系統的第一章；舊版 270 地點、124 武學等資料尚未全部轉成隊伍章節。

## 研究與採用範圍

《煙雨江湖》的[開發者介紹](https://apps.apple.com/cn/app/id1464655502)強調探索、思考與選擇，並列出官方 Wiki。其[官方入駐介紹](https://www.taptap.cn/app/169054)也以在江湖中成長、探險與角色經歷為中心。

開發者指向的 Wiki 中，[名詞詳解](https://wiki.biligame.com/yanyu/游戏内名词详解)整理了聚氣、真元、速度、招架等概念；[武學篇](https://wiki.biligame.com/yanyu/游戏攻略/【烟雨江湖】武学篇)整理套路、內功與輕功。這些是玩家整理資料，並非公開的官方伺服器程式。本章採用「四人角色分工、三類武學、真元與調息、先手與前後排」作為設計參考，沒有宣稱公式等同原作。

用戶提供的兩張畫面只作介面與戰鬥呈現參考，沒有當成遊戲背景或素材打包。角色姿勢、場景與紙張取自用戶要求沿用的 JY-Mini OL；見 `assets/journey/SOURCE.txt`。

## 戰鬥規則

每輪準備時可替每個存活角色選普攻、外功主動招式、守勢與目標。沒有下令時預設普攻。進行回合後依速度由高到低逐個出手，過程顯示攻擊、傷害、治療、封招與毒血狀態。空白鍵推進，委託會自動規劃與推進；關閉後在本輪結束停下。

| 規則 | 本章實作 |
| --- | --- |
| 真元 | 初始 50、上限 100，每 25 為一格；主動消耗 50 或 75。 |
| 聚氣 | 任一方完成一次普攻，全體存活者各獲得自身聚氣值；主動與守勢不觸發此全體脈衝。 |
| 調息 | 外功主動有 2–3 個後續回合的調息，未就緒時按鈕顯示原因。 |
| 攻擊與防禦 | 基礎傷害為 `max(8, int(攻擊 × 招式倍率) − 有效防禦)`；破甲時有效防禦減半。 |
| 主角天賦 | 目標已有流血或破甲時，傷害乘 1.3。 |
| 守勢 | 當輪受到的傷害乘 0.4，回復自身 12 真元；前排守勢者能攔截打向後排的攻勢。 |
| 閃避 | 機率為 `身法 / 180`；踏雪步給 12 身法。未閃避的招式才附加負面狀態。 |
| 流血／毒 | 受影響者出手前分別受 20／25 傷害，持續兩次；可被回春拂穴清除。 |
| 封招 | 取消目標蓄力並跳過下一次行動。 |
| 站位 | 三路、兩排。近戰有前排存活時先打前排，未指定有效目標時優先鄰近路；越陣招可指定後排。佔位會交換同伴。 |
| 用藥 | 回合準備時為選中的受傷同伴回復最多 140 氣血，每回合全隊限一次，實際消耗背包。 |
| 勝敗 | 敵人全倒即勝；己方全倒或超過 40 輪即敗。戰敗與撤退不發獎，回客棧可再準備，銀兩修為不倒扣。 |

黑風寨主以「蓄力 → 下輪橫掃前排」交替攻擊，可封招中斷。毒砂客隔輪越陣施毒。委託會讓劍客攻後排、醫者在需要時治療、棍衛保留控制以對付蓄力；玩家可自己改令。

故事選擇影響首領戰：先救病人使全隊起始真元增加 25；封存毒砂使毒砂客攻擊減少 15。兩者皆保留密信、可完成故事，但江湖誌會記下不同處理方式。

## 武學與角色成長

每人各激發一門外功、內功與輕功。角色固定自身外功方向，主角可按師門解鎖其他外功；兵器類型由所激發外功決定。內功／輕功的實際加成列在武學頁。

| 成長 | 條件與成本 |
| --- | --- |
| 消點 | 必須在演武坪；每重耗 `12 + 當前重數 × 3` 學點。 |
| 自修 | 每完整五秒一個週期，耗 `8 + 當前重數 × 3`；不足時停，不提前給獎。移動、開戰、匯入／讀檔會停止。 |
| 上限 | 本章十重。未入門時最多二重，須先選擇師門才能深入。 |
| 成長效果 | 每重 +28 氣血、+7 攻擊，內功另計其氣血、防禦、聚氣增減。 |
| 華山進階 | 華山入門、主角三重、至少一場勝利，向師父消耗 20 學點學華山劍法。 |

這些成本是新章節平衡，與舊版重建的金庸 Online 消點／自修系統分開。舊版規則保留在原遊戲模式。

## 存檔與相容性

原 `youxia_save.json` 保留 version 1 和 character，新增獨立 chapter 欄位。匯出同時包含兩者；舊備份沒有 chapter 時開新章，舊角色仍在。新章不把舊角色的龐大數值套進新隊伍戰鬥。匯入驗證章節容器、角色 ID、陣位、武學和數量；不恢復未完成戰鬥、自修或移動。

新章目前是單機。原有 Steam、LAN、WebSocket、多人互動與生活技能從「設定 → 舊版江湖」開啟，左上「青溪新章」返回。新章同伴不是其他玩家，也沒有宣稱完成新戰鬥的多人同步。
