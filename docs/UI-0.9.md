# v0.9.0 遊戲介面與人物動作

場景鋪滿遊戲視窗，左上為人物與主線追蹤，右上為小地圖，右下為隊伍、武功、行囊、記事、地圖及選單。對話採底部紙卷與人物半身像；戰鬥為上方戰場配下方隊員指令盤。行囊改為 40 格物品視窗，仍只有目前首章已實作的兩種交易物品，空格不代表新增物品內容。

人物以同一份 imagegen 參考重新生成，包含十二種人物外觀、主角兵器變體及前／側／背行走圖。出招使用預備、蓄勢、出手、收勢；目前是分格姿勢動畫，尚非骨骼動畫或長序列逐幀動畫。

行走改用每秒 185 世界像素、加減速、依實際距離換步、停止即站立與平滑鏡頭。道路路徑會在保留通行限制的前提下拉直，斜向路徑須通過兩側轉角檢查。人物以腳底樞紐定點，攻擊動作共用同一比例。

快捷鍵：C 隊伍、K 武學、I 行囊、J 記事、M 地圖、D 每日、Esc 返回江湖、F5 保存。瀏覽器的 Windows 下載、存檔備份、還原及全螢幕收在右上 ☰ 選單。

JYX2 只完成來源清點：320 筆人物、85 筆場景、98 筆武功、200 筆物品、140 筆戰鬥配置及 1,020 個 Lua 事件檔。事件檔不是任務數量。其 LICENSE 與社區協議限制外部移植，原劇本、對話與資源尚未移入本專案；需先確認授權範圍。此次發布不宣稱已完成 JYX2 全內容移植。
